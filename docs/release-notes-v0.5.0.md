## VRAM Radar 0.5.0

Windows、Apple Silicon Mac 与 Intel Mac 的下一版正式稳定更新。

### 下载

- Windows：`VRAMRadar-Setup-0.5.0.exe`。覆盖安装后，原开始菜单和桌面快捷方式继续指向同一个 `VRAMRadar.exe`。
- macOS：`VRAMRadar-0.5.0-macos.zip`。Apple Silicon 与 Intel 应用仍放在同一个下载包内，由对应架构的 Mac 分别验证后再发布。

### 主要更新

- 千台服务器场景下，主列表每页显示 50 台，右侧快速目录只保留 80 个可见入口；搜索、筛选、前后跳转和当前位置仍覆盖完整服务器集合。
- 超过 64 个节点或 256 张 GPU 的 Slurm 集群默认显示卡型、分区和容量汇总。节点明细按需展开，每页 75 条，并绑定快照版本，避免翻页时混合两次刷新结果。
- 资源推荐支持 GPU 数量、单卡空闲显存、卡型、分区、同节点要求和结果数量；常用条件可以保存为视图，匹配结果仍只在用户主动查询后显示。
- 右侧目录增加收藏、最近使用与当前用户任务筛选。任务分类只显示当前登录账号自己的 Slurm 任务或 Direct SSH GPU 进程。
- 服务器可以单独暂停/恢复监控；全局自动刷新也可暂停。符合已保存资源条件时可发送一次本地通知，并带有冷却时间，避免重复打扰。
- Windows 通知区域菜单现在显示简要资源状态，并提供显示窗口、立即刷新、打开设置、暂停/继续自动监控和退出。关闭按钮可在设置中选择“收起到通知区域”或“退出应用”。
- 增加已保存连接测试、复制脱敏诊断和打开本地日志目录。诊断不包含主机名、SSH 别名、用户名、路径、凭据、命令或远程原始数据。
- 远程输出限制为单次 8 MiB、最多 8 路并发捕获；千卡刷新不再因多个异常大响应造成无界内存峰值。

### macOS 分发边界

若本版沿用当前无 Apple Developer 凭据的发布方式，两个 macOS 应用都未使用 Developer ID 签名且未公证。首次打开时请在 Finder 中右键应用，选择“打开”，并仅在信任本仓库时确认系统提示。正式 Release 只有在 Windows、Apple Silicon、Intel 及最终合包验证全部成功后才会创建。
