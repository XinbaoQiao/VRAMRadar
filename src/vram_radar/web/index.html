先弄清楚要找什么

SSH 配置通常是一个名为 config、没有扩展名的文本文件。终端命令中的 ssh gpu-lab 里，gpu-lab 就是显存雷达要导入的服务器别名。

Windows 教程PowerShell 是 Windows 自带的命令窗口查看步骤收起
先打开 PowerShell

点击右侧按钮即可打开；也可以按 Windows 键，搜索 PowerShell。这里只打开窗口，不会自动执行命令。

1

让 OpenSSH 告诉你它读取了哪个文件

点击命令右侧的“复制”，粘贴到刚打开的 PowerShell，再按 Enter。输出中的 Reading configuration data 后面就是配置文件路径。命令不连接服务器；若配置含 Match exec，OpenSSH 仍可能运行其中的本地判断命令。

ssh -G -v any-host-name 2>&1 | Select-String "Reading configuration data"
2

查看常用目录

如果上一步没有显示用户配置，检查 %USERPROFILE%\.ssh\config 或 %HOME%\.ssh\config。

Get-ChildItem -Force "$HOME\.ssh"
还没有 config 文件？创建并打开一个

下面的命令只会确保 .ssh 目录存在，然后用记事本打开配置文件；已有文件不会被清空。

New-Item -ItemType Directory -Force "$HOME\.ssh" | Out-Null; notepad "$HOME\.ssh\config"
macOS 教程“终端”是 macOS 自带的命令窗口查看步骤收起
先打开“终端”

点击右侧按钮即可打开；也可以按 Command + 空格，搜索“终端”。这里只打开窗口，不会自动执行命令。

1

让 OpenSSH 告诉你它读取了哪个文件

点击命令右侧的“复制”，粘贴到刚打开的终端，再按 Return。输出中的 Reading configuration data 后面就是配置文件路径。命令不连接服务器；若配置含 Match exec，OpenSSH 仍可能运行其中的本地判断命令。

ssh -G -v any-host-name 2>&1 | grep "Reading configuration data"
2

查看常用目录

通常是 ~/.ssh/config；也可能是 ~/.config/ssh/config、Colima 或 OrbStack 的配置。

ls -la ~/.ssh
还没有 config 文件？创建并打开一个

下面的命令会创建标准目录和文件、设置推荐权限，再用文本编辑器打开。

mkdir -p ~/.ssh && touch ~/.ssh/config && chmod 600 ~/.ssh/config && open -e ~/.ssh/config
配置文件应该写什么？查看最小示例

把示例中的地址和用户名替换为自己的信息。gpu-lab 是以后在终端和显存雷达中看到的别名。

Host gpu-lab
    HostName gpu.example.org
    User researcher
使用 VS Code / Cursor Remote-SSH 或其他工具？

在 VS Code、Cursor、VSCodium 或 Windsurf 的设置中搜索 Remote.SSH: Config File 或 remote.SSH.configFile。复制显示的完整路径，粘贴到上方“服务器设置文件路径”，再点击“导入并替换列表”。

PuTTY Session 不是 OpenSSH 配置；WSL 中的 ~/.ssh/config 也属于 Linux 环境。请先把所需别名转换或复制到当前 Windows/macOS 系统能读取的 OpenSSH config。

找到路径以后
  1. 把完整路径粘贴到上方输入框。
  2. 点击“导入并替换列表”。
  3. 检查服务器类型和登录方式，最后点击“保存并开始验证”。
